# UI Guideline — Absensi TK Khoiru Ummah

## 1. Arah visual
Modern futuristic SaaS yang bersih, ramah, profesional, dan tidak terlalu ramai. Gunakan panel terang, garis tipis, sudut membulat, serta aksen hijau yang terukur.

## 2. Palet warna
- **Forest Green:** `#236B4E` — tombol utama, navigasi aktif.
- **Fresh Green:** `#69A884` — aksen, grafik, indikator positif.
- **Cream:** `#F7F3E8` — latar pendamping.
- **Warm White:** `#FFFEFB` — permukaan/kartu.
- **Ink:** `#23312B` — teks utama.
- **Muted:** `#758078` — teks sekunder.
- **Border:** `#E5E9E2` — garis pemisah.
- **Danger:** `#C94C4C` — aksi berisiko/peringatan.

## 3. Tata letak
- Sidebar desktop yang dapat diciutkan; drawer pada layar kecil.
- Header berisi judul halaman, periode aktif, dan menu pengguna.
- Konten memakai grid responsif dengan ruang kosong yang cukup.
- Dashboard: kartu statistik, grafik/indikator ringkas, aktivitas terakhir.
- Tabel: header jelas, pencarian/filter di atas, aksi per baris, empty state.
- Form tambah/edit menggunakan modal atau panel samping yang konsisten.

## 4. Tipografi dan komponen
- Gunakan font sans-serif modern (mis. Inter atau system UI).
- Judul halaman 24–30 px desktop; teks isi 14–16 px.
- Tombol dan input minimal 40–44 px tinggi.
- Radius kartu 14–18 px; bayangan sangat lembut.
- Ikon sederhana dan konsisten; jangan mengandalkan warna saja untuk menyatakan status.

## 5. Status absensi
- Hadir: hijau.
- Izin: biru/teal.
- Sakit: amber.
- Alpa: merah.
Setiap status tetap menampilkan label teks.

## 6. Aksesibilitas dan responsif
- Kontras teks memadai, label input selalu terlihat.
- Fokus keyboard terlihat dan urutan tab logis.
- Tabel memiliki alternatif tampilan yang bisa digulir pada layar kecil.
- Jangan menyampaikan status hanya melalui warna.
- Gunakan konfirmasi sebelum menghapus data.

## 7. Halaman utama
Login, Dashboard, Data Siswa, Data Guru, Kelompok Kelas, Tahun Ajaran & Semester, Absensi Harian, Rekapitulasi Absensi, Narasi Perkembangan, Laporan PDF, dan halaman akses ditolak/empty state bila diperlukan.
