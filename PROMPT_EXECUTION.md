# Prompt Execution — Memulai Proyek

Salin prompt ini ke agen coding setelah pengguna menyetujui Phase 2.

---
Kamu adalah front-end engineer yang mengikuti kontrak `AGENTS.md`. Baca `PRD.md`, `UI-GUIDELINE.md`, dan `IMPLEMENTATION_PLAN.md` terlebih dahulu.

**Tugas saat ini: Phase 2 — Fondasi UI saja.**

Bangun fondasi prototipe Sistem Informasi Absensi Siswa berbasis web pada Tahfizh Plus Khoiru Ummah Tingkat TK Bogor Utara menggunakan React + Vite. Node.js digunakan untuk menjalankan toolchain. Fokus hanya pada front-end dan data dummy lokal.

Kebutuhan fase ini:
1. Siapkan struktur proyek dan routing yang sederhana.
2. Buat design tokens untuk warna putih, cream, dan hijau sesuai UI-GUIDELINE.
3. Buat layout SaaS responsif: sidebar, header, area konten, dan navigasi.
4. Buat halaman login demo serta simulasi logout/role demo.
5. Tambahkan dataset dummy yang jelas bukan data nyata.
6. Pastikan halaman Dashboard dan menu fitur lain memiliki placeholder yang konsisten; jangan implementasikan fitur fase berikutnya secara penuh.
7. Sediakan README berisi cara instalasi dan menjalankan proyek.
8. Jalankan build/check yang tersedia dan perbaiki error pada fase ini.

Batasan:
- Jangan membuat backend/API/database atau autentikasi produksi.
- Jangan menambahkan fitur di luar PRD.
- Jangan lanjut ke Phase 3 tanpa persetujuan eksplisit pengguna.
- Jangan menyatakan tugas selesai jika build belum diperiksa.
- Jika ada keputusan penting yang tidak ditentukan dokumen, tanyakan terlebih dahulu.

Setelah selesai, tampilkan preview, daftar file yang berubah, hasil pemeriksaan, batasan, lalu berhenti dan minta persetujuan untuk Phase 3.
